# Vila Dea · Recepsion

Aplikacion recepsioni për Vila Dea (Sarandë). Gjuha e ekranit është shqip.

## Nisja

```bash
npm install
npm run dev
```

Hapet te [http://127.0.0.1:5173](http://127.0.0.1:5173). Pa backend, përgjigjet vijnë nga MSW (`VITE_USE_MOCKS=true`) dhe “sot” është `2026-09-21`.

## Komanda

| Komanda | Çfarë bën |
|---|---|
| `npm run dev` | serveri i zhvillimit |
| `npm run build` | kontrolli TypeScript + build |
| `npm test` | teste njësie (vitest) |
| `npm run test:e2e` | tre flukset në Playwright |
| `npm run lint` | eslint + stylelint |
